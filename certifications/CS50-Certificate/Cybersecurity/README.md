## Course Overview

This course covers fundamental concepts of cybersecurity through five main areas:

- **Securing Accounts** — Authentication, passwords, multi-factor authentication
- **Securing Data** — Encryption, hashing, data protection
- **Securing Systems** — Operating system security, privilege separation
- **Securing Software** — Memory safety, vulnerabilities, secure coding practices
- **Preserving Privacy** — Privacy-enhancing technologies and threats

## Final Project

**Title:** Analysis of the PS5 Relapse Jailbreak (September 2026)

A case study of a real-world software security incident involving:

- WebKit browser vulnerability and sandbox escape
- Use-After-Free (UAF) vulnerability in the kernel
- Classic privilege escalation chain: Browser → Userland → Kernel
- Impact analysis, risks, and security lessons learned
