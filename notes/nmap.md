# Шпаргалка по `nmap`

Быстрый справочник по разведке хостов, сканированию портов, определению сервисов и запуску NSE-скриптов в лабораторных средах.

> **Примечание по безопасности:** используйте `nmap` только в собственных виртуальных лабораториях, локальных сетях и на разрешённых стендах.

## 1. Обнаружение активных хостов (Host Discovery)

```bash
# Пинг-сканирование подсети без сканирования портов
nmap -sn 192.168.56.0/24

# Сканирование конкретного диапазона или списка хостов
nmap -sn 192.168.56.1-50
nmap -sn 192.168.56.10 192.168.56.20

# Пропустить этап проверки доступности (считать хост живым, даже если ICMP заблокирован)
nmap -Pn 192.0.2.20
```

---

## 2. Типы сканирования портов

```bash
# TCP SYN-сканирование (полуоткрытое, быстрое, требует sudo)
sudo nmap -sS 192.0.2.20

# TCP Connect-сканирование (полное 3-way handshake, работает без root)
nmap -sT 192.0.2.20

# UDP-сканирование (медленнее TCP, полезно для DNS 53, SNMP 161, DHCP 67/68)
sudo nmap -sU 192.0.2.20

# Комбинированное TCP SYN + UDP сканирование
sudo nmap -sS -sU -p T:80,443,U:53,161 192.0.2.20
```

## 3. Выбор портов и скорость

```bash
# Конкретные порты или диапазон
nmap -p 22,80,443,8080 192.0.2.20
nmap -p 1-1000 192.0.2.20

# Все 65535 TCP-портов
nmap -p- 192.0.2.20

# Топ-100 самых частых портов (быстрый обзор)
nmap --top-ports 100 192.0.2.20
# или короткий флаг:
nmap -F 192.0.2.20

# Управление скоростью (-T0..T5; T3 — стандарт, T4 — быстрее для стабильной локальной сети)
nmap -T4 -p- 192.168.56.20
```

## 4. Определение версий сервисов, ОС и NSE-скрипты

```bash
# Определение версий служб и баннеров (-sV)
nmap -sV -p 22,80,443 192.0.2.20

# Агрессивное сканирование: версии сервисов + ОС + базовые скрипты + трассировка (-A)
sudo nmap -A -p 80,443 192.0.2.20

# Запуск стандартных безопасных NSE-скриптов (-sC)
nmap -sC -sV -p 80,443 192.0.2.20

# Запуск конкретного скрипта или категории (например, проверка HTTP-заголовков и методов)
nmap -p 80,443 --script http-title,http-headers,http-methods 192.0.2.20
nmap -p 443 --script ssl-cert,ssl-enum-ciphers 192.0.2.20
```

## 5. Отладка, читаемость вывода и сохранение отчётов

```bash
# Не резолвить DNS-имена (-n) и показывать только открытые порты (--open)
nmap -n --open -p- 192.168.56.20

# Показать причину статуса порта (например, syn-ack, reset, no-response)
nmap --reason -p 22,80,8081 127.0.0.1

# Отслеживать отправляемые и получаемые пакеты в реальном времени
sudo nmap --packet-trace -p 80,8081 127.0.0.1

# Сохранить результаты в обычный текст (-oN), XML (-oX) или сразу во все форматы (-oA)
nmap -sC -sV 192.0.2.20 -oA scan_result
```

## 6. Статусы портов в выводе `nmap`

| Статус | Что означает на уровне пакетов |
|---|---|
| **`open`** | Приложение принимает соединения (на `SYN` пришёл `SYN-ACK`). |
| **`closed`** | Хост доступен, но порт никто не слушает (на `SYN` пришёл `RST`). |
| **`filtered`** | Пакеты блокируются фаерволом или теряются (ответа нет или пришёл ICMP unreachable). |
| **`unfiltered`** | Порт доступен для прощупывания (например, при `ACK`-сканировании), но открыт он или закрыт — не определено. |
| **`open\|filtered`** | Нет ответа (часто при `UDP` или стелс-сканировании): либо порт открыт и молчит, либо отфильтрован. |
